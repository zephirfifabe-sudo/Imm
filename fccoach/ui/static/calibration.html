Calibration du terrain

1. Image de référence

Prends une image de jeu normale (caméra habituelle, pas de ralenti), où l'on voit bien des lignes du terrain.

Contrôle : lignes du terrain reprojetées

Les lignes jaunes doivent tomber sur les lignes blanches. Sinon, corrige les points et enregistre à nouveau.

2. Cliquer les points

  1. Choisis un point du terrain ci-dessous (il s'allume sur le schéma).
  2. Clique exactement sur ce point dans l'image.
  3. Au moins 4 points, bien répartis (pas tous alignés) ; 6 à 8 c'est mieux.

Ensuite

La calibration est gardée pour les matchs suivants. Quand la caméra bouge (panoramique, zoom), l'homographie se recalcule toute seule à partir des lignes. Recalibre seulement si tu changes de réglage de caméra dans le jeu.
